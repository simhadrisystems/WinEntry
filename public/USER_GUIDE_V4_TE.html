1 WinEntry గురించి

WinEntry ని Simhadri Systems వారు Telugu రాష్ట్రాల్లోని licensed retail wine & liquor వ్యాపారాల కఠినమైన రోజువారీ stock reconciliation అవసరాలను తీర్చడానికి design & engineer చేశారు. ఇది ఏ retail వ్యాపారానికైనా — unit-based stock tracking అవసరమయ్యే అన్ని రంగాలకు — పనికొచ్చే powerful inventory management tool.

App ఏమి చేస్తుంది

WinEntry అత్యంత కీలకమైన రోజువారీ reconciliation process ని — "opening vs. closing" balance — automate చేస్తుంది. అధిక volume గల retail వ్యాపారాలకు ఇది చాలా అవసరం.

  • Unit-Level Tracking — అనేక brands, categories మరియు వివిధ sizes అంతటా inventory manage చేయండి (bottles, cases, packets, bags మొదలైనవి)
  • Daily Reconciliation — రోజువారీ purchases, sales మరియు expenses record చేసి, accurate daily stock balance sheets తక్షణమే generate చేయండి
  • Calculated Sales — Opening Balance + Purchases − Closing Balance = Daily Sale — ప్రతి product మరియు size కు automatically calculate అవుతుంది
  • Multilingual Interface — ప్రస్తుతం English మరియు Telugu support చేస్తుంది; కనీస మార్పులతో ఇతర Indian భాషలకు కూడా localise చేయవచ్చు
  • Privacy-First Design — default గా పూర్తిగా offline పని చేస్తుంది; optional cloud backup మాత్రమే data బయటకు పంపుతుంది
  • Excel Export — ప్రతి report మరియు record ని audits, accounts లేదా regulatory submission కోసం Excel కి export చేయవచ్చు

దీన్ని వాడడం ఎందుకు లాభదాయకం

వ్యాపారుల కోసం, వ్యాపారులే తయారు చేసింది. Retail licensees యొక్క విశేష అవసరాల నుండి పుట్టిన WinEntry, peers మధ్య share చేయబడే professional-grade tool గా అందించబడుతోంది. Feedback మరియు నిరంతర మెరుగుదల కోసం community ని promote చేస్తుంది.

మానవ తప్పులను తొలగిస్తుంది. కాగితంపై manual entries కు బదులు digital logging వాడడం వల్ల mathematical errors మరియు financial discrepancies గణనీయంగా తగ్గుతాయి.

అధికంగా customize చేయగలిగేది. Licensed retail trade కు అనువుగా ఉన్నా, underlying logic ఏ retail sector కైనా — Dairy, Hardware, Cosmetics — code మార్పులు లేకుండా adapt చేయవచ్చు.

Checklist లో 4 steps ఉన్నాయి. Step 1 మరియు Step 2 తప్పనిసరి. Card మాయమవ్వాలంటే Step 3 లేదా Step 4 లో ఏదైనా ఒకటి కూడా complete చేయాలి — అప్పుడే రోజువారీ వ్యాపారం మొదలుపెట్టవచ్చు.

Language toggle: ఈ dialog పై భాగంలో English / తెలుగు buttons app language ని switch చేస్తాయి. మార్పు వెంటనే అన్ని screens కు apply అవుతుంది. Settings నుండి ఎప్పుడైనా మళ్ళీ మార్చవచ్చు.

Step 1 — Business Info

మీ business పేరు మరియు owner వివరాలు exported reports మరియు Home screen లో header గా కనిపిస్తాయి.

  1. "Set Up Business Information" పక్కన Set Up తాకండి — Business Info screen తెరుచుకుంటుంది
  2. Fields పూరించండి:
    • Owner Name — మీ పూర్తి పేరు
    • Business Name (తప్పనిసరి) — మీ వ్యాపారం లేదా దుకాణం పేరు
    • Licence / Reg. No — registration లేదా licence number (locally మాత్రమే store అవుతుంది, admin కి share కాదు)
    • Address Lines 1 & 2, Location — దుకాణం చిరునామా మరియు ప్రాంతం
    • Phone — 10-digit mobile number
  3. Save & Register తాకండి
  4. Confirmation dialog లో admin కి share చేయబడే fields వివరిస్తుంది. Save & Register తాకి confirm చేయండి.

Step 2 — Product List Import చేయడం

Admin యొక్క standard product master list (product codes, పేర్లు, sizes మరియు prices) మీ phone కి download చేస్తుంది.

  1. "Import Product List" పక్కన Download తాకండి
  2. Progress spinner కనిపిస్తుంది — connection speed బట్టి 5–30 seconds వేచి ఉండండి
  3. Complete అయిన తర్వాత green tick కనిపిస్తుంది

"Download" బదులుగా "Request Access" కనిపిస్తే: మీ account ని admin ఇంకా activate చేయలేదు. "Request Access" తాకి email లేదా WhatsApp ద్వారా activation request పంపండి. Admin మీ account ని invited list కు add చేసిన తర్వాత తిరిగి వచ్చి Download చేయండి.

Download తర్వాత, Items/Products → Product Display Order కి వెళ్ళి products ని మీరు stock count చేసే క్రమంలో arrange చేయండి. ఇది daily closing entry వేగంగా చేయడానికి సహాయపడుతుంది.

ఇక్కడ set చేసిన order app అంతటా consistently కనిపిస్తుంది — Daily Stock Entry, Opening Stock మరియు అన్ని reports లో products ఈ sequence లో appear అవుతాయి. Reorder చేయడానికి: Product Display Order తాకి Edit switch on చేయండి, తర్వాత left వైపు drag handle తో rows move చేయండి లేదా ప్రతి product పక్కన ↑ ↓ nudge arrows తాకండి. పూర్తయినప్పుడు Renumber & Save తాకండి. Edit switch off చేసిన స్థితిలో ఏదైనా product row ని double-tap చేస్తే దాన్ని deactivate చేయవచ్చు — deactivated products Inactive section కి move అవుతాయి మరియు daily stock entry లో కనిపించవు.

Step 3 — Sample Data Load చేయడం (ఐచ్ఛికం)

Sample data వల్ల real figures enter చేయడానికి ముందు app ని practice చేయవచ్చు. Dummy opening stock మరియు కొన్ని రోజుల transactions load అవుతాయి — అన్ని screens ని real data తో చూడవచ్చు.

Real opening stock enter చేయాలంటే ఈ step skip చేసి నేరుగా Step 4 కి వెళ్ళండి.
  1. "Import Sample / Test Data (Optional)" పక్కన Load తాకండి
  2. Date picker తెరుచుకుంటుంది — sample data కు opening balance తేదీగా ఏ తేదీ కావాలో ఎంచుకోండి. Default: 7 రోజుల క్రితం.
  3. OK తాకండి — sample data background లో load అవుతుంది (10–30 seconds)

Step 4 — Opening Stock Setup చేయడం

Sample data కాకుండా real data తో start చేస్తున్నారంటే, ప్రారంభ inventory గా ప్రతి product మరియు size కి actual unit count enter చేయాలి. ఇది మొదటిసారి live వ్యాపారం ప్రారంభించేటప్పుడు ఒకసారి మాత్రమే చేస్తారు. రెండు పద్ధతులు ఉన్నాయి — మీకు అనుకూలమైనది ఎంచుకోండి.

Option A — Manual Entry (Screen లో నేరుగా)

చిన్న product lists కు suitable.

  1. "Setup Opening Stock (manual)" పక్కన Enter తాకండి
  2. Opening Stock Setup screen తెరుచుకుంటుంది
  3. పై భాగంలో మీ మొదటి trading తేదీ ఎంచుకోండి
  4. ప్రతి product కు size fields తాకి మీ దగ్గర ఉన్న unit count type చేయండి
  5. Size fields మరియు products మధ్య వేగంగా move చేయడానికి keyboard Next key వాడండి
  6. దిగువన SAVE తాకండి — confirm చేయడానికి ముందు total unit count చూపిస్తుంది

Option B — Excel నుండి Import చేయడం (పెద్ద lists కు వేగంగా)

Opening stock figures ఇప్పటికే spreadsheet లో ఉంటే, లేదా product list పెద్దగా ఉంటే Excel import చాలా వేగంగా ఉంటుంది.

  1. "Setup Opening Stock (manual)" పక్కన Enter తాకి Opening Stock Setup screen తెరవండి
  2. ⋮ (కుడివైపు పై menu) → Download Template తాకండి
  3. App మీ phone Downloads folder లో pre-filled Excel file save చేస్తుంది. Template లో ప్రతి product కు ఒక row, ప్రతి size కు (L, QQ, PP, NN, DD) ఒక column ఉంటుంది. Product codes ముందే fill అయి ఉంటాయి — వాటిని మార్చకండి.
  4. Computer లో లేదా phone లో Google Sheets / Microsoft Excel లో template తెరవండి
  5. ప్రతి product మరియు size కు quantity columns లో opening stock counts enter చేయండి. ఆ size లేకపోతే blank వదలండి లేదా 0 enter చేయండి.
  6. File save చేసి phone కు transfer చేయండి (WhatsApp, Google Drive, email లేదా USB ద్వారా)
  7. Opening Stock Setup screen లో తిరిగి వచ్చి ⋮ → Import from Excel తాకండి
  8. Phone storage నుండి saved file ఎంచుకోండి
  9. App figures import చేసి import result summary చూపిస్తుంది (Section 12 చూడండి)

Excel నుండి Closing Balances Import చేయడం

Products ఎక్కువగా ఉన్నప్పుడు, లేదా closing stock ఇప్పటికే spreadsheet లో record అయి ఉంటే, Excel నుండి directly import చేయడం వేగంగా ఉంటుంది.

  1. Daily Stock screen లో ⋮ → Download Closing Template తాకండి
  2. App Downloads folder లో pre-filled Excel file save చేస్తుంది. Product codes మరియు names ముందే fill అయి ఉంటాయి — వాటిని మార్చకండి.
  3. Computer లో లేదా Google Sheets / Microsoft Excel లో template తెరవండి
  4. ప్రతి product మరియు size కు closing balance counts enter చేయండి. ఆ size లేకపోతే blank వదలండి లేదా 0 enter చేయండి.
  5. Date column లో మీరు enter చేస్తున్న trading తేదీ set చేయండి.
  6. File save చేసి phone కు transfer చేయండి (WhatsApp, Google Drive, email లేదా USB ద్వారా)
  7. Daily Stock screen లో తిరిగి వచ్చి ⋮ → Import Closing తాకండి
  8. Phone storage నుండి file ఎంచుకోండి
  9. App closing balances import చేసి result summary చూపిస్తుంది (Section 12 చూడండి)

Purchase Entry — product detail

Invoice వివరాలు (పై సగం)

  • Invoice No — delivery document నుండి supplier invoice number
  • Reference No — ఈ delivery కు unique reference (permit లేదా transport number వంటివి) — duplicate imports నివారించడానికి వాడతారు
  • Supplier — dropdown నుండి ఎంచుకోండి లేదా manually type చేయండి
  • Date — goods receive అయిన తేదీ (default: నేడు)
  • Notes — ఐచ్ఛిక గమనికలు

Product వివరాలు (కింది సగం)

  1. Product ఎంచుకోవడానికి Select Product తాకండి
  2. Receive అయిన ప్రతి size కు enter చేయండి:
    • Cases — పూర్తిగా sealed cases సంఖ్య
    • Loose — individual loose units (partial case)
    • Price — per unit price (product master నుండి auto-fill అవుతుంది)
  3. Total units = (Cases × units per case) + Loose, Cost = Total × Price — automatically calculate అవుతుంది
  4. అదే invoice లో మరొక product add చేయడానికి Add Another Product తాకండి
  5. పూర్తయినప్పుడు Save తాకండి
ఈ delivery లో ఒక size రాకపోతే దాని Cases మరియు Loose fields zero లో వదలండి.

Purchase Edit లేదా Delete చేయడం

List లో ఏదైనా purchase ని double-tap చేస్తే Edit, Delete లేదా Insert Here options తో action dialog తెరుచుకుంటుంది. Deletions permanent అవుతాయి మరియు ఆ తేదీ daily stock totals వెంటనే update అవుతాయి.

అదే Invoice లో Multiple Items చేర్చడం

Purchases list లో existing purchase ని double-tap చేసి Insert Here ఎంచుకోండి. అదే invoice number, తేదీ మరియు supplier తో pre-filled కొత్త purchase form తెరుచుకుంటుంది — product మాత్రమే మార్చండి.

Excel నుండి Purchases Import చేయడం

చాలా products తో delivery వచ్చినప్పుడు, లేదా bulk historical invoices enter చేసేటప్పుడు, Excel నుండి import చేయడం చాలా వేగంగా ఉంటుంది.

  1. Purchases screen లో ⋮ → Download Template తాకండి
  2. App Downloads folder లో pre-filled Excel template save చేస్తుంది. Columns: Date, Invoice No, Reference No, Supplier, Product Code, మరియు ప్రతి size కు Cases, Loose, Price.
  3. Computer లో లేదా Google Sheets / Microsoft Excel లో template తెరవండి
  4. ప్రతి invoice యొక్క ప్రతి product line కు ఒక row fill చేయండి:
    • Delivery Date enter చేయండి (format: DD-MM-YYYY లేదా YYYY-MM-DD)
    • Delivery document నుండి Invoice No మరియు Reference No enter చేయండి
    • Supplier పేరు enter చేయండి
    • Product Code column లో సరైన product row వెతకండి
    • Receive అయిన ప్రతి size కు Cases మరియు Loose enter చేయండి
    • ప్రతి size కు per unit Price enter చేయండి
  5. ప్రతి product కు rows repeat చేయండి. ఒకే file లో అనేక invoices enter చేయవచ్చు — ప్రతి delivery కు వేరే Invoice No వాడండి.
  6. File save చేసి phone కు transfer చేయండి
  7. Purchases screen లో తిరిగి వచ్చి ⋮ → Import from Excel తాకండి
  8. Phone storage నుండి file ఎంచుకోండి
  9. App అన్ని rows import చేసి result summary చూపిస్తుంది (Section 12 చూడండి)

11 Cloud Drive Backup

Cloud backup ఐచ్ఛికం. దాన్ని లేకుండా app పూర్తిగా offline పని చేస్తుంది. Enable చేసినప్పుడు, మీ daily stock, purchases మరియు day-end summaries admin's Drive workspace లో private Google Sheet లో store అవుతాయి — మీ personal Drive నుండి వేరుగా.

మీ data, మీ నియంత్రణ. Google తో sign in చేయడం వల్ల sync start కాదు. Backup enable చేసి terms accept చేసిన తర్వాత మాత్రమే data phone వదలుతుంది.

Enable చేయడం ఎలా

  1. Register చేయండి — Settings → Business Info కి వెళ్ళి business name fill చేసి Save & Register తాకండి
  2. Workspace request చేయండి — Settings → Drive Backup card తాకి → Request Drive Backup తాకండి
  3. Consent terms చదవండి — ఏ data store అవుతుందో మరియు admin కు read access ఉంటుందని dialog వివరిస్తుంది
  4. I Agree — Enable Backup తాకండి
  5. App admin's system ని contact చేస్తుంది:
    • Invited list లో ఉంటే → workspace వెంటనే create అవుతుంది → "Drive Backup Active" green లో చూపిస్తుంది
    • Invited list లో లేకపోతే → "Drive Backup Pending" చూపిస్తుంది — admin activate చేస్తారు

Excel Import — ఎలా పని చేస్తుంది

ప్రతి data type కు import system ఒకే three-step pattern follow చేస్తుంది:

Step 1 — Template Download చేయండి

ఎప్పుడూ app లో నుండే template download చేయడం మొదలుపెట్టండి. Template లో మీ product codes మరియు app expect చేసే exact format లో column headings ముందే fill అయి ఉంటాయి. Import file scratch నుండి create చేయకండి — template మాత్రమే వాడండి.

Step 2 — Template నింపండి

Computer లో లేదా phone లో (Google Sheets, Microsoft Excel) template తెరవండి. Quantity/value columns లో మీ data enter చేయండి. Product codes, column headings లేదా sheet structure మార్చకండి. .xlsx గా save చేయండి.

Step 3 — Transfer చేసి Import చేయండి

Filled file ని phone కు transfer చేయండి (WhatsApp, Google Drive, email లేదా USB). App లో ⋮ → relevant Import option తాకి file ఎంచుకోండి. App commit చేయడానికి ముందు ప్రతి row validate చేస్తుంది.
